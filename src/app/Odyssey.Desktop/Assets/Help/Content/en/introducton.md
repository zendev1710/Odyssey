# Odyssey Help

Odyssey is a complete client for Eressea. You can view your map, search, give orders, and you almost only need to leave the program to send mails to your allies. Almost...  

This documentation is built up around the following chapters:

- The menus
- The docks
- Reference
- FAQ
- Feedback and Support

In this documentation there are some additional tables and descriptions of the orders from the Eressea manual. These may, however, not be complete or completely up-to-date. When in doubt use the official rules at https://wiki.eressea.de.  

Unfortunately this documentation is incomplete.
Several parts are missing or have to be expanded on.
It may also happen that this documentation is not completely up-to-date, since Magellan is under constant development.
If you miss anything, leave us a note at the Magellan bug tracker.
Of course any kind of help is welcome. The most important resource for recent information is our Website: <https://magellan2.github.io>
