# Installation of graphic sets

This feature has not been tested for a long time. If you use it successfully, have alternative graphics sets, or have ideas on how to use it, please share your experiences with the development team.

The graphic sets are zip files. However, you don't have to unzip them after downloading, you can simply save them somewhere. Then you have to enter the graphics set in Magellan as a [resource path](resources.md). To do this, open the Magellan options dialogue and switch to ['Resources'](../menus/extras/options_resources.md). There click on the button 'New path...'. A file selection dialogue appears in which you select the graphics set that Magellan should use. The zip file should now appear at the top of the list (with a strange 'jar:file:/' at the front - that's how it should be). After closing the options and pressing **[Shift-F5](../menu/extras/index.md)**, there is a good chance that the selected graphics set will be used for the map.

Graphic sets for Magellan are available at [http://eressea.upb.de/magellan/graphicsets.shtml](http://eressea.upb.de/magellan/graphicsets.shtml)4
