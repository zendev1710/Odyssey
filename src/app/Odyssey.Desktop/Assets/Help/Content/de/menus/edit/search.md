# Suchen

STRG-F

Mit dieser Funktion kann man den Report nach Stichwörtern durchsuchen und so "verlorene" Einheiten, Schiffe usw. finden. Dabei kann man den Suchbereich in folgendem Dialog einstellen:

![menu_extras_search](../../images/menu_extras_search.gif)

Das Feld **_Suchmuster_** kann dabei auch leer bleiben. Die Suche nach einem leeren Suchmuster und dem Suchbereich "Schiffe" liefert z.B. als Ergebnis alle Schiffe, die im Report auftauchen.

Im Block **_Attribut-Suchbereich_** kann man einstellen welche Attribute eines Objekts bei der Suche berücksichtigt werden sollen. Auch kann man hier die Suche auf eine bestimmte Partei einschränken. 'Suche Wörter einzeln' sucht nach allen Objekten, die eins der eingegeben Wörter als Teil enthalten. 'Nur ganze Wörter' findet nur Objekte, die das Suchmuster als Ganzes enthalten. 'Reguläre Ausdrücke' sucht nach solchen, zum Beispiel findet ' `.*bauer` ' Bauer, Bergbauer und Vogelbauern und ' `^B.*auer$` ' findet Bauer und Bergbauer, aber nicht Vogelbauern.

Der Block **_Objekt-Suchbereich_** erlaubt das Einschränken der Suche auf Einheiten, Gebäude, Schiffe, Regionen und Verräter.

Mit Klick auf das Suchergebnis wird das entsprechende Objekt im Hauptfenster angezeigt.
