# Inseln erfassen

Bei Anwahl dieses Menüpunktes ordnet Magellan zusammenhängende Landregionen einer Insel zu. Damit die Inseln angezeigt werden, muß die entsprechende Einstellung in den [Optionen](../extras/options_region.md) aktiviert sein. Inseln können benannt werden, indem der entsprechende Eintrag in der [Regionsübersicht](../../docks/regions.md) ausgewählt und in der [Namensansicht](../../docks/name.md) bearbeitet wird.
