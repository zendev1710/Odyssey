# Export CR

![menu_file_crexport](../../images/menu_file_crexport.gif)

Les options suivantes sont disponibles pour exporter un CR :

**Save** :
    Enregistre le fichier de commande à l'emplacement spécifié.
**Clipboard** : Copie le fichier de commande dans le presse-papiers :
    Copie le fichier de commande dans le presse-papiers. De là, il peut être facilement copié dans un programme de messagerie, par exemple.
**Fermer** :
    Ferme la boîte de dialogue.
