# Signets

## Signets

Les signets sont des raccourcis vers des éléments spécifiques du monde Eressea.
Ils vous permettent de naviguer rapidement vers vos éléments préférés ou les plus utilisés.

Les éléments suivants peuvent être ajoutés en tant que signets :

- îles
- régions
- bâtiments
- bateaux
- factions
- unités, qu'elles soient les vôtres ou celles d'autres factions

### Naviguer entre les signets

Vous pouvez utiliser la vue "Signets" pour afficher tous vos signets et naviguer facilement entre eux, en sélectionnnant l'item correspondant dans la liste.
Un signet sélectionné dans la vue "Signets" est sélectionné dans la vue "Exporateur".

Le menu "Signets" vous permet :

- de sélectionner le signet suivant (raccourci clavier : F2)
- de sélectionner le signet précédent (raccourci clavier : Shift + F2)
- d'importer un ensemble de signets (par exemple, depuis un fichier JSON exporté précédemment avec Magellan)
- d'enregistrer les signets en cours dans un ensemble de signets (fichier JSON) pour les réutiliser plus tard ou les partager avec d'autres joueurs
- de supprimer tous les signets de l'ensemble de signets courant

## Ensemble de signets

Les signets définis peuvent être regroupés en ensemble de signets, qui sont des collections de signets que vous pouvez nommer et gérer ensemble.

L'ensemble des signets défini par défaut est nommé "Default" et ne peut pas être supprimé.

Vous pouvez créer autant d'ensembles de signets que vous le souhaitez pour organiser vos signets selon vos préférences.

Un ensemble de signets peut être implicitement rattaché à un rapport .cr ouvert, ce qui signifie que les signets de cet ensemble seront automatiquement chargés lorsque vous ouvrirez ce rapport.

Cela vous permet de personnaliser votre expérience de navigation en fonction du rapport que vous consultez.
