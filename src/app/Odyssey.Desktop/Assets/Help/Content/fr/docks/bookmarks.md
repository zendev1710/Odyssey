# Signets

Le dock des signets affiche tous les signets.

![Historique](../images/windows_history.gif)

Vous pouvez appuyer sur Ctrl+F2 pour ajouter un signet pour l'objet sélectionné (unité, région, navire, bâtiment, île). Si un tel signet existe déjà, il est supprimé. En appuyant sur F2 ou Shift-F2 , respectivement, vous pouvez avancer ou reculer dans la liste des signets. Le [menu signets] (../menus/bookmarks/index.html) fournit des commandes pour sauvegarder vos signets dans un fichier ou les charger à partir d'un fichier.
