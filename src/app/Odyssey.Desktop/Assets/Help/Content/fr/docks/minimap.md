# MiniMap

![windows_minimap](../images/windows_minimap.gif)

Cette carte présente une vue d'aigle, permettant de voir une plus grande partie du monde. Si une région est sélectionnée ici, la carte principale sera centrée sur cette région, et la région sera ouverte dans l'arbre des régions. Comme pour la carte principale, la mini-carte offre une série d'[options] (../menus/extras/options_map.html).
