# Plugin de l'éditeur de groupe

Ce plugin fait partie de la version standard de Magellan 2.0 et permet de définir rapidement et facilement les statuts HELFE des groupes d'une faction. Une relation HELFE avec une faction peut être définie pour chaque groupe sur la base d'une matrice.

Ce plugin est conçu comme un dock et ne peut donc être ouvert que de cette manière. Pour ce faire, cliquez avec le bouton droit de la souris n'importe où dans la fenêtre principale de Magellan ou sélectionnez "Group HELFE Status Editor" dans le menu "Desktop". Un nouveau dock s'ouvrira.

Ce dock est divisé en trois parties. En haut, vous verrez une liste des factions pour lesquelles vous pouvez modifier les statuts d'aide. Sélectionnez votre faction si nécessaire. Au centre, vous verrez tous les groupes (sur l'axe X) et toutes les factions (sur l'axe Y). Chaque cellule définit la relation entre un groupe et une faction. Modifiez ces relations à votre guise. Veillez à respecter les règles du PbEM concerné. En bas de la fenêtre, un bouton permet d'appliquer les paramètres. Si vous cliquez dessus, les états d'aide seront définis sur la première unité connue du groupe.
