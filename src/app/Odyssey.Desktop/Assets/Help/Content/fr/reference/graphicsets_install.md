# Installation de jeux graphiques

Cette fonctionnalité n'a pas été testée depuis longtemps. Si vous l'utilisez avec succès, si vous avez d'autres jeux graphiques ou si vous avez des idées sur la manière de l'utiliser, veuillez faire part de votre expérience à l'équipe de développement.

Les jeux de graphiques sont des fichiers zip. Cependant, vous n'avez pas besoin de les décompresser après les avoir téléchargés, vous pouvez simplement les enregistrer quelque part. Ensuite, vous devez entrer le jeu de graphiques dans Magellan en tant que [resource path] (resources.md). Pour ce faire, ouvrez la boîte de dialogue des options de Magellan et passez à ['Ressources'](../menus/extras/options_resources.md). Cliquez ensuite sur le bouton "Nouveau chemin...". Une boîte de dialogue de sélection de fichiers apparaît, dans laquelle vous sélectionnez le jeu de graphiques que Magellan doit utiliser. Le fichier zip devrait maintenant apparaître en haut de la liste (avec un étrange 'jar:file:/' à l'avant - c'est comme ça que ça devrait être). Après avoir fermé les options et appuyé sur **[Shift-F5](../menu/extras/index.md)**, il y a de fortes chances que le jeu graphique sélectionné soit utilisé pour la carte.

Les jeux graphiques pour Magellan sont disponibles à l'adresse suivante : [http://eressea.upb.de/magellan/graphicsets.shtml](http://eressea.upb.de/magellan/graphicsets.shtml)4
