# RULES

## Buildings

### Academy

Can be built in any land.

### Caravanserai

Can be built in any land but is useful only in **deserts**.

A caravanserai allows you to build **roads** in **deserts**.

### Dam

Can be built in any land but is useful only in **swamps**.

Dam allows you to build roads in **swamps**.

### Harbour

A region can have only one harbour.

Can be built in any land but is useful only in:

- desert
- glacier
- highland
- iceberg
- mountain
- swamp
- volcano

Allows ships larger than a boat to land in regions which are not plains or forests.

### Inn

Can be built in any land.

Units in a Inn regenerate 50% faster.

### Lighthouse

Can be built in any land.

### Mage Tower

Mages in a Mage Tower are strengthened and can cast spells more easily and faster.

Can be built in any land.

### Mine

Units inside a mine extract iron, laen and adamantium more easily and faster.

Can be built in any land but is useful mainly on:

- glacier
- mountain

mmaybe also on:
- iceberg?
- volcano?

### Monument

Can be built in any land.

No effect.

### Quarry

Units inside a quary produce stones more easily and faster.

Can be built in any land but is useful mainly on:

- glacier
- mountain

mmaybe also on:
- iceberg?
- volcano?

### Sawmill

Units inside a sawmill produce wood more easily and faster.

Can be built in any land but is useful only on:

- forest
- plain

### Smithy

Units inside a smithy produce weapons and armours more easily and faster.

Can be built in any land.

### Stable

Units inside a stable produce horses more easily and faster.

Can be built in any land but is more useful where horses live, e.g.:

- forest
- plain

### Stonecircle

Can be built in any land.

### Tunnel

Can be built in any land but is useful only in **glacier**.

A tunnel allows you to build **roads** in **glacier**.
